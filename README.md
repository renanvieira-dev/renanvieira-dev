### ⚡ Visão Geral

Desenvolvedor **Full Stack** com formação em design de interfaces e foco rigoroso em **Application Security (AppSec) e DevSecOps**. Desenvolvo ecossistemas de ponta a ponta: desde arquiteturas de front-end dinâmicas e APIs assíncronas até automação de pipelines multimédia e segurança defensiva.

* 🌐 **Full Stack Core:** React, Next.js (App Router), TypeScript, Tailwind CSS v4, Node.js e Python.
* 🛡️ **Segurança & AppSec:** Testes de invasão (Pentest), modelagem de ameaças, SSDLC, Kali Linux e automação defensiva.
* 🎛️ **Engenharia de Mídia & Áudio:** Processamento de sinais, fluxos em lote com FFmpeg, Web Audio API, Demucs e prototipagem interativa na Godot 4.
* 📍 **Localização:** Curitiba, PR — Brasil.
