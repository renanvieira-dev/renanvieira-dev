### 👨‍💻 Sobre Mim

Desenvolvedor **Full Stack** com formação sólida em design de interfaces e foco crescente em **Application Security (AppSec) e DevSecOps**. Crio aplicações completas — do design de sistemas escaláveis e pipelines de áudio/vídeo ao desenvolvimento front-end reativo, APIs assíncronas e práticas de segurança defensiva e ofensiva.

* 🌐 **Full Stack Web**: Arquitetura moderna com React, Next.js (App Router), TypeScript, Node.js e Python.
* 🛡️ **Cybersecurity & AppSec**: Práticas de código seguro, modelagem de ameaças, testes de invasão (Pentest), análise de vulnerabilidades e automação em Kali Linux.
* ⚙️ **Pipelines & Mídia**: Processamento de mídia e ferramentas desktop com FFmpeg, Web Audio API, Demucs, Python (CustomTkinter/Selenium) e desenvolvimento de jogos na Godot 4.
* 📍 Curitiba - PR, Brasil.
