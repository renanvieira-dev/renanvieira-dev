### ⚡ Visão Geral

Desenvolvedor **Full Stack** com sólida vivência em **UI/UX e design de sistemas**, especializado na criação de aplicações resilientes, performáticas e com foco contínuo em **Application Security (AppSec) e DevSecOps**.

* 💻 **Full Stack Moderno**: Desenvolvimento de ecossistemas completos com React, Next.js (App Router), TypeScript, Tailwind CSS v4, Node.js e Python (FastAPI/Django).
* 🛡️ **Segurança Defensiva e Ofensiva**: Práticas rigorosas de segurança aplicadas ao ciclo de desenvolvimento de software (SSDLC), modelagem de ameaças, testes de invasão e rotinas no Kali Linux.
* 🎥 **Engenharia de Mídia e Automação**: Criação de fluxos e scripts de automação multimédia de alto desempenho com FFmpeg, Web Audio API, Demucs e prototipagem na Godot 4.
* 📍 Curitiba, PR — Brasil.
